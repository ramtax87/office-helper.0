# Alltagsprompts (Deutsch, nach dem Aufbau)

In dem KI-Werkzeug verwenden, an das das System angebunden wurde. Normale Sätze funktionieren überall. Werkzeuge mit
eigenen Befehlen (z. B. Claude Code, Gemini CLI) haben zusätzlich Kurzbefehle wie `/tageslauf`. Englische Sätze
funktionieren auch (`en/prompts/DAILY_PROMPTS.md`).

## Tageslauf
```
Tageslauf.
```
```
Ich habe gerade 12 Briefe nach _Eingang gescannt. Bearbeite sie und sag mir, welche eine Antwort brauchen.
```
