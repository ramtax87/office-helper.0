# Daily prompts (English, after the build)

Use these in the AI tool the system was wired into. Plain sentences work everywhere; tools with custom commands
(e.g. Claude Code, Gemini CLI) also get short commands like `/run`. German sentences work too
(`de/prompts/ALLTAG.md`). Letters the system drafts are always German.

## Daily run
```
Daily run.
```
```
I just scanned 12 letters into _Eingang. Process them and tell me which ones need an answer.
```
